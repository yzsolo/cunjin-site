寸金隐私政策

更新日期：2026 年 11 月 6 日 开发者：zhen yang

寸金展示黄金、白银、铜、铂金和钯金的公开参考行情。应用不要求注册，不接入证券或银行账户，不读取持仓、通讯录、照片或精确位置，也未集成广告和第三方统计 SDK。

本机保存的信息

挂件位置、显示模式、置顶和磁吸设置，以及最近一次有效报价保存在本机。App Store 版保存在应用沙盒中。应用不主动把这些本地设置或缓存文件上传给开发者。卸载应用后，残留的本地应用数据可由你在 macOS 中删除。

行情请求与第三方数据源

为获得最新价格，应用会通过 HTTPS 直接访问 api.gold-api.com。请求包含金属代码、币种和应用版本等必要信息；数据源服务器还会接收到你的 IP 地址和请求时间。开发者未为寸金搭建收集用户信息的服务器。

Gold API 的公开隐私政策说明，其可能记录 API 使用信息、时间戳、IP 地址，以及根据 IP 推断的大致地区，用于服务维护、分析和安全等目的；数据也可能跨地区处理。上述数据由行情服务提供方按其政策管理。关闭应用可停止后续行情请求；自选列表关闭后会停止请求铂金和钯金，隐藏铜挂件后会停止其后续刷新。金银菜单栏报价在隐藏挂件时仍会更新，完全停止联网请退出寸金。

第三方隐私政策：https://gold-api.com/privacy

第三方服务条款：https://gold-api.com/terms

应用不使用上述信息开展跨应用广告跟踪。应用采用一次性买断方式，购买与支付由 Apple App Store 处理；开发者不接收你的付款卡号或账单支付凭据。

报价用途

价格为第三方参考行情，人民币价格包含单位换算与汇率折算；来源时间不保证是交易所的最新成交时间。应用不执行金融交易，也不提供个性化投资建议。

联系与政策更新

关于寸金的隐私或使用问题，可邮件联系 yzsolo125@gmail.com；涉及 Gold API 保存的数据，可通过其网站联系服务提供方。若应用的数据处理方式发生变化，本政策会随应用更新。

本静态网站不运行广告、分析脚本或数据收集表单；托管服务商会接收到提供网页所需的连接信息。
